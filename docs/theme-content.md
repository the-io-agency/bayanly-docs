# Theme content

Theme content covers your theme's buttons, labels, section text (for example the homepage) and checkout and account text. Choose the theme at the top; you can prepare an unpublished theme without affecting your live store. Text is grouped by page and section.

## Translation space

Shopify allows a limited number of theme translations per language (3,400). The space meter shows how much is used.

If the theme is close to full, use **Free up space** on the **Import & export** page. It removes translations of Shopify's own checkout and account text, which Shopify already translates.
