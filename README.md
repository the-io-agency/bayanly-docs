# Bayanly Help Center

Public help docs for **Bayanly: Store Translation**, published with GitHub Pages:
https://the-io-agency.github.io/bayanly-docs/

## Editing

Edit the Markdown files in `docs/` on github.com (open a file → pencil icon → Commit changes).
The site rebuilds and publishes automatically in about a minute.
To add a page, create `docs/<name>.md` and list it under `nav` in `mkdocs.yml`.

## Preview locally

```bash
pip install -r requirements.txt
mkdocs serve
```
